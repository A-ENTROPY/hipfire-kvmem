========================================================================
 KVMem + ROCmFP4 + DFlash2  ——  解压即用版
========================================================================

 三步走：
   1) 解压本 ZIP
   2) 把下载的 .gguf 模型丢进 models\ 目录
      （下载清单见 models\把模型放这里.md）
   3) 双击 start-kvmem.bat

 脚本会自动扫描 models\、识别主模型/草稿模型/视觉投影器、
 自动组合最优配置并启动。浏览器打开 http://127.0.0.1:18200/

------------------------------------------------------------------------
 两种启动方式
------------------------------------------------------------------------
 A) 快速启动（零依赖，推荐先用这个）
      双击 start-kvmem.bat
    自动扫 models\ -> 挑模型 -> 起服务。改参数只能靠命令行参数。

 B) 中文调参面板（功能最全，需要 Node.js）
      双击 start-panel.bat
    浏览器打开 http://127.0.0.1:18201/
    - 所有可调参数做成中文表单，每项都标了本机实测推荐值
    - 保存到 config.json，下次启动自动沿用
    - 「保存并重启」一键生效（约 10 秒）
    - 模型下拉框自动列出 models\ 里扫到的所有模型，随时换
    - 启动 / 停止 / 重启服务、看实时日志
    没装 Node.js 也能用 A)，面板只是更方便。

------------------------------------------------------------------------
 常用参数（全都不填也能跑，仅 A 方式）
------------------------------------------------------------------------
   -List                  只列出识别到的模型，不启动
   -DryRun                只打印将执行的命令
   -ModelsDir "D:\models" 模型放在别的目录
   -Spec none             关闭推测解码（最省显存）
   -Spec mtp              强制用 MTP
   -DraftTokens 2         手动指定草稿数（0 = 自动；推荐 MTP 用 2 / DFlash2 用 3）
   -Context 32768         小上下文，省显存
   -Reserve 131072        允许更长的单轮输出（更费显存）

------------------------------------------------------------------------
 性能提示（实测于 RX 7900 XTX / gfx1100 / ROCm 7.2）
------------------------------------------------------------------------
 * 启动器默认【不传】 --threads 与 --flash-attn：
    旧版（v0.16/9-27 构建）加这两项会让速度腰斩，本版重测已无影响（±0.7%）。
    仍然建议留空 —— 没有收益，且留空就是启动器与面板的默认值。
 * 草稿数用 3 最佳（MTP 与 DFlash2 都是 3）。
   2026-10-05 交替 A/B：MTP 英文/中文 n2 = 62.8/66.7 → n3 = 66.9/71.8（+6.6%/+7.7%）。
   加到 4 反而更慢（英文掉到 57.8）。
 * 实测解码（同一台机器，生成 256 token，MTP3/DFlash3）：
     ROCmFP4 主模型 原生              43.0 tok/s
     ROCmFP4 + MTP 草稿（首选）       英文 66.9 / 中文 71.8 tok/s   +56%
     ROCmFP4 + DFlash2（备选）        英文 68.4 tok/s   +59%
     IQ3_S 主模型 原生                45.1 tok/s
     IQ3_S + 自带 MTP 焊接头          58.2 tok/s   +29%
   MTP 接受率：英文 67.7% / 中文 73.1%（KVMEM_PERF=1 时打印 KVMEM_SPEC_STATS）。
 * 长提示词（约 5.4K token）预填充约 800~950 tok/s；短提示词（约 1K）读数偏低（610~625）属正常预热。
 * 上下文「容量」免费（256K 可分配），但填满的上下文会慢：
   1.2K 提示词 ≈61 tok/s，9K ≈59，27K ≈52（MTP3，服务端预热后）。
   把 --kvmem-budget 调小（如 8192）可再提速约 16%，但输出变成近似（未常驻块不被注意）；
   要正确输出请保持 budget ≥ 提示词长度。
 * 单轮生成长度受 -Reserve（--kvmem-gen-reserve）限制，含思考内容。
