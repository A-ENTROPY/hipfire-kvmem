# 把模型放在这个目录里 / Put your models here

启动脚本会**自动扫描本目录**下的所有 `.gguf` 文件，自动识别出「主模型 / 草稿模型 / 视觉投影器」并组合出最优配置。
**你不需要改任何命令行参数。**

---

## 需要下载什么

### ① 主模型（必需，二选一）

**推荐 —— 速度最快**

| 文件名 | 大小 | 说明 |
|---|---|---|
| `Qwen3.8-27B-Q4_0_ROCMFP4_STRIX.gguf` | 13.75 GB | ROCmFP4 量化，配合 ② 的 MTP 草稿实测 68 tok/s |

直接下载（**本机实测用的就是这一份**，SHA256 已逐字节核对一致）：

```
https://huggingface.co/kingjones777/Qwen3.8-27B-ROCmFP4-STRIX-MTP-GGUF/resolve/main/Qwen3.8-27B-Q4_0_ROCMFP4_STRIX.gguf
```

国内镜像：把 `huggingface.co` 换成 `hf-mirror.com`（同一个路径）。

同一个仓库里也有 `mtp-Qwen3.8-27B-Q4_0.gguf`（1.56 GB），可以当 ② 的草稿模型用。

想自己量化（可选，需要 F16/BF16 源模型）：用**本包自带的 `llama-quantize`**，预设名 `Q4_0_ROCMFP4_STRIX`。
ROCmFP4 格式与预设来自 https://github.com/charlie12345/rocmfp4-llama

也可以直接使用 HuggingFace 上现成的其它 ROCmFP4 GGUF（搜索关键词 `ROCmFP4`），同样能被识别。

**备选 —— KVMem 官方配方（模型自带 MTP 焊接头，无需草稿模型）**

| 文件名 | 大小 | 说明 |
|---|---|---|
| `Qwen3.8-27B-GSQ-RCO-IQ3_S-mtp.gguf` | 11.29 GB | 长上下文优先，用自带 MTP 头实测 58 tok/s |

下载：https://huggingface.co/ISTA-DASLab/Qwen3.8-27B-GSQ-RCO-GGUF

## 放好之后

直接双击上一层的 `start-kvmem.bat`，脚本会打印扫描结果和将要使用的配置，然后启动服务。

想先看看识别到了什么、不启动服务：

```
start-kvmem.bat -List
```

模型放在别处也行：

```
start-kvmem.bat -ModelsDir "D:\my-models"
```

## 下载提示

- 大文件建议用下载工具或 `curl -L -C -` 断点续传（GitHub/HF 直连不稳时很常见）
- HuggingFace 在国内可用镜像站：把 `huggingface.co` 换成 `hf-mirror.com` 即可
- 本发行包**不含模型权重**，请遵守各模型自身的许可条款
