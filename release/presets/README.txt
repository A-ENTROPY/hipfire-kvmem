这些是面板的预设文件，面板里「预设」一栏可以直接加载。

推荐两个：
  性能档.json    meanq-cosine 打分，288 页窗口（36864 token），实测中位 32.4 tok/s
  质量档.json    page-softmax 打分 + 图传播 α=0.2，同窗口，实测中位 32.6 tok/s

注意：散文最快.json 与 长文_256k_分层.json 用的是 DFlash 推测解码。
v2.0.0 的实测里 DFlash 比 MTP 慢一倍多（单步 219 ms vs 77.8 ms，接受率约 20%），
且深上下文还有掉速风险，详见根目录 README 的「已知问题」。建议先用 性能档 / 质量档。
